## Automated Capture Script

To re-generate all screenshots programmatically at any time:

```bash
# Ensure local backend engine is running
DICTY_SCREENSHOTS_DIR="$(pwd)/docs/screenshots" ./DictyClient/.build/arm64-apple-macosx/debug/Dicty --capture-screenshots
```
